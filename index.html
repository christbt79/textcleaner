    Textcleaner
    
  
    
    An all-in-one text cleaner and formatter. Paste something that came from a
    PDF, Word, InDesign, an email or a web page, and get text that behaves
    when you paste it somewhere else.
  
    
  
    Your text stays here
    
  
    
    Every operation runs in this browser tab. There is no server, no account,
    no analytics and no network request. Closing the tab is all it takes to
    get rid of the text; the page also works with no connection at all.
  
    
  
    Worth knowing
    
  
      
    
    • The bar at the top lists what is actually wrong with the text you pasted. Each item switches on the operation that fixes it.
      • 
    
    • Reveal hidden shows the characters you cannot see: non-breaking spaces, zero-width spaces, soft hyphens and tabs.
      • 
    
    • Operations always run in the same order regardless of the order you switch them on, so the result never depends on what you clicked first.
      • 
    
    • Copy writes plain text only, so nothing carries formatting into the next application.
